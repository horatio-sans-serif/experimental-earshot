# Earshot (working name)

A walk-through sound exhibit for a yard. Small solar speakers find their own positions, share one
clock, and play a scene authored on a map of the yard. No animatronics: sound only.

First use: rehearsing real places (a crowd, a storm, a busy station) at home, at a volume and pace
you control, before facing them for real.

```
Scene tool → Content → World model → Renderer → Speaker nodes → listener walking
```

Status (2026-10-18): concept only. First production is a browser simulator of the yard, the
speakers and a walking listener, heard on headphones. Detail and history: `docs/EVOLUTION.md`.
